# Nota — versiones PDF

Los tres documentos de esta carpeta existen también en versión PDF, con
el mismo contenido (el manual incluye además las capturas de pantalla
del procedimiento):

- `Manual-Instalacion.pdf` — 6 páginas, con capturas.
- `Guia-Personalizacion.pdf` — 4 páginas.
- `Licencias.pdf` — 4 páginas.

Las versiones PDF se suben por separado a este repositorio (por la
interfaz web de GitHub) y/o se adjuntan a la Release, porque la subida
por herramientas automatizadas de este proyecto solo admite archivos de
texto. Las versiones en Markdown de esta carpeta (`MANUAL-INSTALACION.md`,
`GUIA-PERSONALIZACION.md`, `LICENCIAS.md`) tienen el mismo contenido y
pueden leerse directamente desde GitHub.
