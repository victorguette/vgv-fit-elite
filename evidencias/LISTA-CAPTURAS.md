# Lista de capturas de evidencia

Las capturas de las pruebas de importación y revisión visual se suben
por separado a esta carpeta (por la interfaz web de GitHub), porque la
subida por herramientas automatizadas de este proyecto solo admite
archivos de texto. Esta lista describe cada archivo para comprobar que
la subida está completa y qué muestra cada captura. Todas son archivos
JPG originales, sin recortar.

El informe completo de las pruebas está en `EVIDENCIA.md` y
`VERIFICATION-REPORT.md` (en esta misma carpeta).
